# Holberton School - Web Back-End

## 📖 About
This repository gathers the projects completed during the **Web Back-End** track at **Holberton School**. It currently focuses on asynchronous programming in Python with `asyncio`: coroutines, tasks, async generators and async comprehensions.

---

## 🛠️ General Requirements & Environment
* **OS:** Ubuntu 20.04 LTS
* **Interpreter:** `python3` (version 3.8.5+)
* **Style Guide:** All Python source files are meant to follow **PEP 8** (check with `pycodestyle`).
* **Typing:** Functions are type-annotated and documented with docstrings.

---

## 📚 Project Overview

| Directory | Core Concepts / Highlights | Key Files |
| :--- | :--- | :--- |
| [`python_async_function`](python_async_function/) | Coroutines, `await`, `asyncio.as_completed`, `asyncio.create_task`, runtime measurement | `0-basic_async_syntax.py`, `1-concurrent_coroutines.py`, `4-tasks.py` |
| [`python_async_comprehension`](python_async_comprehension/) | Async generators, async comprehensions, `asyncio.gather` | `0-async_generator.py`, `1-async_comprehension.py` |
